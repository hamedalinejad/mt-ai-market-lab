# Contributing to mt-ai-market-lab

## Phase 0 Policy

This repository is currently in **Phase 0 — Documentation First**.

- No production code is accepted until the corresponding Specification is approved.
- All architectural decisions must be recorded as ADRs.
- Documentation changes follow the conventions in `docs/conventions/`.

## How to Contribute

1. Read the Master Blueprint and relevant domain docs.
2. Open an issue describing the proposed change.
3. For documentation: follow the frontmatter standard and template.
4. For ADRs: use the ADR template in `docs/decisions/`.
5. Submit a pull request with clear description and linked issue.

## Documentation Rules

- Every document must have YAML frontmatter.
- Status values: `draft` | `review` | `approved` | `deprecated` | `superseded`
- Use the standard sections defined in the Documentation Template.
- Cross-references must be maintained.

## Code Policy (Future Phases)

- Code must implement an approved Specification.
- Tests and reproducibility are mandatory.
- Resource awareness and safety boundaries must be respected.
