# Architecture Decision Records (ADRs)

Every decision that changes architecture, locks technology, modifies contracts, alters safety boundaries, or changes the data model must have an ADR.

## Structure

```
Context
Problem
Options
Decision
Rationale
Trade-offs
Consequences
Status
```
