# Knowledge Lifecycle

```text
UNKNOWN → CANDIDATE → DISCOVERED → TESTED → VALIDATED
  → ACTIVE → DEGRADED → UNCERTAIN → RETIRED / REJECTED
```

Each transition records evidence edges (Validation, Outcome, Failure).
