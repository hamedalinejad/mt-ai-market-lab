# Statistical Uncertainty (BUG-VAL-P0-006)

`win_rate = 58%` alone is **not** acceptable for promotion claims.

Required with primary metrics:

```text
sample_size
confidence_interval
bootstrap_interval (when applicable)
dispersion
downside_metric
worst_regime
```
