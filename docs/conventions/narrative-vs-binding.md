# Narrative vs Binding

| Layer | Path | Authority |
|-------|------|-----------|
| **Binding** | `docs/contracts/**`, approved vertical-slice docs, ADRs `accepted`/`approved` | Implementation must follow |
| **Narrative consolidated** | `*-MERGED-*` domain files | Context only; TBD sections are **not** binding |

Phase 0 DoD applies to **binding** surfaces for the vertical slice, not every narrative paragraph.
