# Acceptance Criteria

Binding documents **must** use domain-specific IDs:

```text
AC-<DOMAIN>-NN
Given …
When …
Then …
```

Generic AC-01/AC-02 on narrative/merged files are placeholders only and are **not** sufficient for `approved` contracts.
