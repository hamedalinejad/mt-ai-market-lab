# Naming Conventions

## Files

- Use lowercase with hyphens: `market-dna-fingerprint.md`
- Domain folders: `00-project`, `01-system-architecture`, ...
- ADRs: `ADR-XXXX-short-title.md`

## IDs

- Documents: `DOC-XXXX` or `DOC-DOMAIN-XXXX`
- ADRs: `ADR-XXXX`
