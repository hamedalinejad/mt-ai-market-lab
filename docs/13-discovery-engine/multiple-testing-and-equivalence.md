# Multiple Testing and Equivalence

Multiple-testing control is **first-class**.

Candidate identity is not text equality. Normalize:
- algebraically equivalent expressions
- shifted parameterizations
- reordered commutative terms
- duplicate strategy logic
- duplicate feature constructions

Discovery evidence must record the **effective search family** for statistical interpretation.
