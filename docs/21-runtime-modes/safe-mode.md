# Safe Mode

```text
MT5:         ON
Data:        ON
Prediction:  optional
Discovery:   OFF
Learning:    OFF
Signals:     OFF
Trading:     OFF
```

Entry via circuit breakers or operator; exit only after health recovery checks.
